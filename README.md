# AR / ER Dashboard 2028

หน้าเว็บ Dashboard สรุปรายชื่อ Academic Reputation (AR) และ Employer Reputation (ER) สำหรับ QS Ranking 2028

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง repository
3. ไปที่ **Settings → Pages** และเลือก deploy จาก branch `main` / โฟลเดอร์ `/ (root)`

ข้อมูลสรุปอยู่ใน `data.js` หากได้รับข้อมูลชุดใหม่ ให้แก้ตัวเลขในไฟล์นี้แล้ว push ขึ้น GitHub อีกครั้ง
